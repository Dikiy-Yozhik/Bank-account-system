# Bank Account System

Консольное банковское приложение на Java с полным циклом работы с банковскими счетами.

## 🚀 Быстрый запуск

### Windows
```bash
git clone https://github.com/Dikiy-Yozhik/Bank-account-system.git
cd bank-account-system
run.bat
```
### Linux/Mac
```bash
git clone https://github.com/Dikiy-Yozhik/Bank-account-system.git
cd bank-account-system
chmod +x run.sh
./run.sh
```

## ✨ Возможности
🔐 Аутентификация - регистрация и вход с хэшированием паролей

💳 Управление счетами - создание и выбор счетов

💰 Операции - пополнение, снятие, просмотр баланса

📊 История - полная история транзакций с поиском

💾 Сохранение - автоматическое сохранение данных

## 🏗️ Архитектура
```text
src/
├── model/          # Сущности данных
├── service/        # Бизнес-логика  
├── controller/     # Управление приложением
├── view/           # Консольный интерфейс
└── exception/      # Обработка ошибок
```
## 🛠️ Технологии
Java 8+

MVC архитектура

Сериализация данных

SHA-256 хэширование

Кастомная система исключений

## 🎮 Использование
Зарегистрируйте нового пользователя

Войдите в систему

Создайте банковский счет

Выполняйте операции: пополнение, снятие, просмотр истории

Выходите через меню для сохранения данных
